# React Portfolio

A responsive single-page portfolio created with React and Vite.

## Required sections

- About Me
- Projects
- Contact Me

## Run locally

```bash
npm install
npm run dev
```

## Build the project

```bash
npm run build
```

## Before submitting

Edit `src/App.jsx` and replace:

- `your.email@example.com`
- `https://github.com/yourusername`
- `https://linkedin.com/in/yourusername`
- Project links currently set to `#`

## Upload to GitHub

Create a GitHub repository named `react-portfolio`, then run:

```bash
git init
git add .
git commit -m "Create React portfolio"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/react-portfolio.git
git push -u origin main
```

After pushing, import the repository into Vercel and deploy it using the default Vite settings.
